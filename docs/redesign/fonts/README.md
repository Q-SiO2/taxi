# Planning-board fonts

Downloaded 12 October 2026 from the official Google Fonts repository. These are
specimen resources under `docs/`, not application font/theme changes. Font bytes
and license notices are recorded in [manifest.json](manifest.json).

| Local family | Official source | Notice |
| --- | --- | --- |
| Inter | [Inter directory](https://github.com/google/fonts/tree/main/ofl/inter) | [OFL](inter-OFL.txt) |
| Plus Jakarta Sans | [Source directory](https://github.com/google/fonts/tree/main/ofl/plusjakartasans) | [OFL](plusjakartasans-OFL.txt) |
| IBM Plex Sans | [Source directory](https://github.com/google/fonts/tree/main/ofl/ibmplexsans) | [OFL](ibmplexsans-OFL.txt) |
| IBM Plex Sans Arabic | [Source directory](https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic) | [OFL](ibmplexsansarabic-OFL.txt) |
| Noto Sans Arabic | [Source directory](https://github.com/google/fonts/tree/main/ofl/notosansarabic) | [OFL](notosansarabic-OFL.txt) |

Latin families and Noto Sans Arabic use the original variable TTF. IBM Plex Sans
Arabic uses original 400/500/600/700 static TTFs. Files are unmodified; reserved
font names and notices remain intact. Product bundling and native weight/metric
verification belong to the approved implementation wave.
