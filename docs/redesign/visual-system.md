# TaxiMobile — Selected visual system

**Recorded 15 October 2026: owner-selected four-style system.**

The visual identity is Folded Streets, Street Press, Glazed Machine and Notepad.
Use [style-options.md](style-options.md) for their exact base tokens, shape,
typography, motion, preference and implementation contracts. The independent
Forest/Orchid/Electric/Terracotta/Graphite-Lime theme menu is withdrawn.

## Shared foundation

One component and interaction system serves all four styles. Change drawing,
edge/radius/shadow, surface and motion treatment; preserve data, intents, focus
order, hit targets and domain-state authority. All essential text rests on an
opaque surface. Abstract fields are separate decorative layers.

Keep 48 dp icon targets, 56 dp ordinary primary actions and 64 dp critical driver
actions. Labels stay above fields; body/field text starts at 16/24. At enlarged
text, grow content and retain a reachable action footer. Use Arabic line metrics,
start/end alignment and bidi isolation for mixed values; never track Arabic glyphs.
Preserve the existing licensed icon/font resources. Never replace a semantic icon
with an unlabeled brand flourish. Notepad retains the same meaningful icons.

## Four style grammars

- **Folded Streets:** crisp planes, asymmetric complementary edges and hinged
  sections; flowing color is an abstract treatment around stable content.
- **Street Press:** sharp rules, bold print hierarchy and contrasting collage;
  registration is confined to decoration, never jittering text or fare digits.
- **Glazed Machine:** broader tactile forms, restrained stepped shadows and held
  material settling; grain/light is a supporting field, not a central vehicle scene.
- **Notepad:** grayscale ink, ruled organization, square controls and compact
  task-first structure. No decorative field/controller; busy/result/focus remains.

Precise colors, font choices and shape exceptions are in the selected contract.
Dark/outdoor specimens require separate actual contrast/device acceptance; a dark
preview does not authorize automatic night switching or a new preference menu.

## States, maps and animation

Every applicable component supports normal, keyboard focus, pressed, selected,
busy, disabled, validation error, read-only, restricted, offline and reduced-motion
states. State has text and symbol/shape as well as color. In Notepad all semantic
colors become grayscale treatments, with distinctions retained through explicit
labels, icons, weights and outlines. No payment state is inferred from decoration.

Maps remain data surfaces. Do not mirror map geometry for Arabic, show nearby
supply without authority, or turn abstract fields into a route/dispatch animation.
The monochrome map treatment retains marker shapes, route stroke and labels.
No generic hero image is required in the selected identity.

Motion is scoped by the current job. Expressive entry framing has a static rest
pose, finite performance and cancellation; security, active driver, dense console
and consequential review work stay stable. OS reduced motion keeps the selected
style and disables decorative movement. Notepad always disables decorative
movement. Errors, real loading and pending outcomes remain explicit.

## Coverage and acceptance

[Every page](page-atlas.html) and [all 40 components](component-gallery.html) expose
one four-style selector. [Style coverage](style-coverage.md) records all 213 views;
each standalone specification links the contract. These are authored browser
specimens, not claims that 852 native views have been implemented.

Native evidence must cover narrow/large text, EN/FR/AR, keyboard/insets,
assistive labels, actual OS motion settings, lifecycle, assets/frame cost and the
connected phone. Existing alpha, pilot and public release gates remain separate.

[Earlier five-palette proposal](visual-system-before-four-styles.md) is history.
The current selected styles supersede its identity, color, radius and motion
recommendations wherever they conflict.
