The owner likes the interface treatments without the main illustration and now
points toward elaborate abstract animation, moving color gradients and contrasted

Open the [abstract expression lab](abstract-lab.html). Combine an abstract field

stays opaque and steady while color and shape move around it. The animation is
original procedural code; no reference company logo, typeface or artwork is used.

## Three concrete performances

| Study | Static composition | Motion | Identity question |
| --- | --- | --- | --- |
| **Prism current** | Orange, pink, violet, cobalt, cyan, mint and yellow form a diagonal spectral field; a translucent angular color layer intersects it | Gradient position sweeps across the screen; the intersecting field changes angle during one performance | Can this be recognized through angle, band rhythm and transitions rather than being another generic mesh-gradient background? |
| **Cut collage** | Four deliberately contrasting cut planes: cobalt slab, pink slash, yellow paper edge, orange/ink arch fragment | Planes translate and turn at different small rates, framing a steady task surface | Which two or three cut shapes become TaxiMobile's repeatable signature across navigation, selection, receipt and presentation? |
| **Grain and light** | Matte warm pink, blue and mint atmosphere with a fine static dotted texture | A bounded light band crosses the field; color position shifts gently | Can grain and print rhythm connect this softer mode to the sharper collage system? |

The current experiment is a 2,400 ms replayed performance with Stop and scrub,
one cycle, reduced-motion suppression, a defined static pose, and hidden/offscreen
cancellation. It is not an accepted native effect. Gradients do not run continuously
behind amounts or imply matching/dispatch progress. Functional text and actions
are separate from the animated field; status still uses ordinary labels.

## From experiments to an owned signature

Develop a small repeatable grammar rather than a library of unrelated flourishes:

1. Select a characteristic diagonal angle and an asymmetric cut/hinge relationship.
2. Define the spectral color order and its relationship to appearance themes.
3. Specify a crisp static pose, an entrance, a controlled transition and an exit.
4. Carry the same shape language into a selection indicator, chapter separator,
   empty state and receipt edge at three sizes. None requires a main illustration.
5. Preserve the liked interface treatments and compare the result across all 213
   views. The current atlas exposes grammar and theme independently; final field
   placement needs a per-view revision after selection.

Scope animation by job: welcome, browsing and presentation can use the fuller
performance; fare review, cash confirmation and active driver work keep stable
facts/actions with compact or static framing. This keeps the expressive system
coherent without assuming the same amount of movement on every page.

ID-2 in [identity-reset.md](identity-reset.md) now means refining this art-free
signature and its motion shots. ID-3 still covers every page and all component
contracts. Existing alpha, pilot and public release gates remain separate.

## Production and verification

The lab uses CSS gradients, original polygon cuts, a static procedural grain
pattern and a shared timeline. It adds no runtime dependency to the application.
Native delivery may use cached drawing/layers and transforms; shader or complex
blur work requires a measured proof before adoption. Do not infer native package,
memory, frame-time, battery or accessibility acceptance from browser playback.

See [abstract-check.json](abstract-check.json),
