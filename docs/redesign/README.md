# TaxiMobile — Selected identity and complete experience plan

**Four-style direction selected by the owner; recorded 15 October 2026.**

Users choose **Folded Streets, Street Press, Glazed Machine or Notepad**. The
separate color-theme menu is withdrawn. Gradients, collage and grain are treatments
within the expressive styles. No main vehicle/city illustration is required.

## Approval and remaining evidence

Actual application implementation is now authorized and underway. The
[board checkpoint](../board-alpha.md) records the Android four-style/language
renders, persistent preference, hosted recovery and first native cash trip.
The atlas remains a design review tool; it is not the running application.

The four-style direction and user-selection model are selected. No further palette
vote is needed. This selection is distinct from actual native implementation,
per-view/device acceptance, hosted rehearsal and alpha/pilot/public release gates.
The browser specimen preference belongs only to the review tool. The real app's
four-style preference is implemented at the shared theme boundary, with platform
storage adapters and bounded state-retention tests. Actual Android restart
persistence and twelve welcome style/language renders are recorded in the board
checkpoint; those checks do not accept every reachable page or iOS runtime.

Keep KMP/Compose, FastAPI/PostGIS, native maps, existing web modules and all domain
contracts. Style changes must preserve drafts, current jobs, selection, pending
commands, session fencing and server-owned price/payment/eligibility. Map selection
remains the alpha location flow. Do not introduce unsupported search, messaging,
tracking, payment, identity or emergency capabilities as part of the style work.
